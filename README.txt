Maran Toolbox Pro v1.3 - browser/PWA test build.

Includes fleet selection, ETA, maintenance, drydock, vessel history, budgets with 5-year view (manual data), supplies, local profile, local Activity Center with before/after audit for budget revisions and supply status changes, and file-based export/import.

IMPORTANT: There is NO real online user registration, verified phone login, automatic cloud synchronization, or push notifications. GitHub Pages hosts static files only. To share now: export selected updates, send the .mtb file to your colleague via an authorized channel, and have them import it. Historical Excel data not yet migrated.

Publish: create a NEW GitHub repository maran-toolbox-pro. Upload the CONTENTS of this folder to the root, not the ZIP itself. Settings > Pages > Deploy from a branch > main /root. Wait for deployment. The existing marine-eta-calculator repository is not affected.

Warning: A public GitHub Pages site exposes all published code and bundled files. Never upload private budgets, orders, or records to the repository. Local browser data is device-specific; export backups. Exported .mtb files are not encrypted.
